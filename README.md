## 📂 Архитектура репозитория

Всё строго рассортировано по категориям, чтобы вы могли легко найти нужный софт. Кликайте по папкам, чтобы перейти к проектам!

| Категория | Описание | Основные технологии |
|:---|:---|:---|
| 📥 **[dl/](./dl)** | Парсеры, краулеры и загрузчики контента. Умные боты для обхода защит (DDoS-Guard, Cloudflare) и скачивания видео/файлов. | `Python`, `Playwright`, `yt-dlp` |
| 🎮 **[games/](./games)** | Reverse Engineering игр, создание модов, распаковщики ресурсов, русификаторы и инъекторы. | `C++`, `Python`, `x64dbg` |

| 🌐 **[web/](./web)** | Разработка сайтов, фронтенд, API, боты для Telegram и Discord. | `React`, `Node.js`, `Aiogram` |

## 🚀 Как начать пользоваться?

Клонируйте этот мега-репозиторий себе на ПК одной командой:

```bash
git clone https://github.com/sakuraidev/SakuraRepo.git
cd SakuraRepo
```

Затем просто перейдите в папку нужного проекта и прочитайте локальный `README.md` для запуска. Например:
```bash
cd dl/Yummy-DL
python3 main.py
```

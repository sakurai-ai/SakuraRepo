## 🚀 Как начать пользоваться?

Клонируйте этот мега-репозиторий себе на ПК одной командой:

```bash
git clone https://github.com/sakurai-ai/SakuraRepo.git
cd SakuraRepo
```

Затем просто перейдите в папку нужного проекта и прочитайте локальный `README.md` для запуска. Например:
```bash
cd dl/Yummy-DL
python3 main.py
```

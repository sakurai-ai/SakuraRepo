# Инструкция по монтированию Google Drive с помощью Rclone

С помощью этой инструкции вы сможете подключить свой Google Диск к системе так, чтобы он выглядел как обычная папка (Linux) или жесткий диск (Windows). После этого вы сможете сохранять скачанные видео прямо в эту папку, и они мгновенно полетят в облако.

---

## 🐧 Для Linux (Удаленный VPS сервер)

### Шаг 1. Установка Rclone и FUSE
FUSE нужен для того, чтобы Linux мог создавать "виртуальные" диски. В **терминале сервера** введите:
```bash
sudo -v ; curl https://rclone.org/install.sh | sudo bash
sudo apt update && sudo apt install -y fuse3
```

### Шаг 2. Настройка подключения
Введите в **терминале сервера** команду:
```bash
rclone config
```
Далее отвечайте на вопросы так:
1. `n` (Создать новое подключение)
2. Имя: `gdrive`
3. Тип: `drive` (Google Drive)
4. `client_id` и `client_secret` — **просто нажмите Enter** (оставьте пустыми).
5. `scope` (Права) — введите `1` (Полный доступ).
6. `service_account_file` — **просто нажмите Enter** (оставьте пустым).
7. `Edit advanced config?` — введите `n` (Нет).
8. `Use auto config?` (Использовать браузер?): 
   * Так как у сервера нет графического экрана, введите **`n`**.
   * Сервер выдаст вам команду вида: `rclone authorize "drive" "eyJ..."`.

### Шаг 3. Авторизация (ВНИМАНИЕ!)
1. Скопируйте выданную сервером команду `rclone authorize...`
2. Откройте **НОВОЕ окно терминала на вашем домашнем ПК** (где тоже должен быть установлен rclone) и вставьте её туда. 
3. На домашнем ПК откроется браузер, вы авторизуетесь, и домашний терминал выдаст длинный код (токен) в фигурных скобках `{...}`.
4. Скопируйте этот код, вернитесь в **терминал сервера** и вставьте его там, где мигает `config_token>`.
5. `Configure this as a Shared Drive?` — ответьте `n`.
6. `Keep this "gdrive" remote?` — ответьте `y`, затем нажмите `q` для выхода из меню.

> **💡 Что делать, если сервер выдал ошибку "empty token found"?**
> Токены "протухают" очень быстро. Если не успели, введите на сервере `rclone config reconnect gdrive:`, снова ответьте `n` про браузер, скопируйте новую команду авторизации, выполните её дома и вставьте новый токен.

### Шаг 4. Монтирование
Создаем папку и привязываем к ней диск:
```bash
mkdir -p ~/gdrive
rclone mount gdrive: ~/gdrive --daemon --vfs-cache-mode writes
```
**Готово!** Теперь в парсере можно указывать путь сохранения: `~/gdrive/Anime` (или любую вложенную папку).

## 🪟 Для Windows (Локальный ПК)

### Шаг 1. Установка
Откройте PowerShell от имени администратора и установите Rclone и WinFsp (виртуальные диски для Windows):
```powershell
winget install Rclone.Rclone
winget install WinFsp.WinFsp
```

### Шаг 2. Настройка подключения
В командной строке `cmd` введите `rclone config`.
Шаги идентичны Линуксу: создаете `gdrive`, тип `drive`, доступ `1`. 
Но на вопросе `Use auto config?` смело жмите **`y`** — браузер откроется сам на вашем компьютере.

### Шаг 3. Монтирование
Чтобы примонтировать Google Диск как диск `G:` в системе "Мой компьютер", введите:
```cmd
rclone mount gdrive: G: --vfs-cache-mode writes
```
*(Окно консоли нужно оставить открытым. Если закрыть — диск отключится).*

**Готово!** Теперь ваш Google Диск виден как флешка `G:`. В парсере указывайте: `G:\Anime`

# 🔞 HHParser (by sakuraidev)

Мощный автоматизированный парсер для **HentaiHaven**.  
Обходит ограничения, извлекает метаданные и собирает прямые ссылки на видео.

[![Python](https://img.shields.io/badge/Made_with-Python-blue?logo=python&logoColor=white&style=for-the-badge&color=fcd1d7)]()
[![Status](https://img.shields.io/badge/Status-Active-brightgreen?style=for-the-badge&color=ffb3c6)]()

---
</div>

## ✨ Возможности
* 🛡️ **Обход защиты:** Встроенный Chrome TLS/HTTP2 impersonation для обхода капчи и блокировок Cloudflare.
* 📋 **Сбор метаданных:** Автоматический парсинг жанров, описаний и тегов.
* 🎥 **Видео-линки:** Быстрое извлечение прямых потоков видео (.m3u8 / .mp4).
* 🎨 **Интерфейс:** Красивый ASCII-интерфейс в терминале.

## 🚀 Быстрый старт (Quick Start)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/sakurai-ai/HHParser.git
   cd HHParser
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите парсер:
   ```bash
   ./start.sh
   # или python main.py (в зависимости от вашего файла запуска)
   ```
